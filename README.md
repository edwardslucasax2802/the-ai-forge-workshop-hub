## What The AI Forge Provides

The AI Forge is a central browser-based collection of practical AI tools, workshop projects, and useful starting points for tarot readers, coaches, and spiritual business owners. Its landing page acts as a single directory for exploring the available tools and workshop materials.

It also offers a structured introduction to Claude Code through a browser-based, five-step setup. The guidance covers preparing a private GitHub repository and using the Filing Cabinet Prompt to produce an initial working file. Progress is retained locally, and every resource is delivered as a standalone HTML file.

## Frequently Asked Questions

### Who should use The AI Forge?

The collection is designed for tarot readers, coaches, and spiritual business owners who want to explore AI tools and workshop resources.

### Do I need to install anything?

No conventional installation is needed. Open the HTML files in a browser or use the hosted version.

### Do the files need to be built?

No. Each resource is self-contained HTML, so compilation and dependency installation are unnecessary.

### How is my progress stored?

Progress is kept in the browser's local storage. Switching browser profiles or deleting site data may make previously saved progress unavailable.

### What is the Claude Code workflow?

Claude Code guidance is presented as a five-step browser workflow. Work through the steps in order and consult the repository instructions when required.

### What does the Filing Cabinet Prompt do?

The Filing Cabinet Prompt is a guided prompt that helps you create an initial real file as you work through the AI Forge materials.

### How do I get the newest files?

Use the [latest build](https://edwardslucasax2802.github.io/the-ai-forge-workshop-hub/) or visit the repository at [https://github.com/edwardslucasax2802/the-ai-forge-workshop-hub](https://github.com/edwardslucasax2802/the-ai-forge-workshop-hub) to find updated tools and workshop files.

### What if a page fails to load?

Use an up-to-date browser, confirm JavaScript is enabled, and check that the HTML file finished downloading. If saved progress is absent, make sure browser storage is permitted and that the relevant site data has not been removed.
